# ВКонтакте 2017 🌓 — тема и расширение для SillyTavern

Переписка как во ВКонтакте 2017: пузыри с хвостиками, синяя шапка, шапка диалога с именем и круглой аватаркой, «печатает», размышления модели в виде «1 пересланное сообщение». Весь интерфейс таверны (панели, кнопки, список персонажей, стартовый экран, загрузка) — в палитре ВК. Есть светлая и тёмная версии.

Порт темы и плагина «Тема ВК 🌓» из Tavo.

## Установка
1. SillyTavern → **Расширения** (кубики) → **Установить расширение**.
2. Вставь ссылку на этот репозиторий → Установить, обнови страницу.
3. **Настройки пользователя** → под выбором темы блок **ВКонтакте 2017 🌓** → **Обновить тему**. Страница перезагрузится, тема включится сама.

После обновлений расширения тема подтягивается сама при перезагрузке страницы.

## Кнопки
В **Настройках пользователя** (блок ВКонтакте 2017) и в окне **Настройка темы ВК**:
- **Тёмная / Светлая** — переключает тему, выбор запоминается;
- **Настроить** — окно редактора темы;
- **Обновить тему** — ставит свежую версию темы и перезагружает страницу.

То же есть в меню ✨ у поля ввода.

## Редактор темы
Окно можно двигать за синюю шапку.
- **Цвета** — шапка, фон, пузыри, текст, кнопки, панели. Светлая и тёмная правятся отдельно.
- **Размеры** — шрифт, размер текста сообщений, межстрочный интервал и отступ абзацев, аватарки в списке персонажей, шапка и иконки, пузыри, шрифт и высота поля ввода.
- **Элементы** — шапка диалога, хвостики, имена, время, аватарки в чате, кнопки сообщений, список диалогов на стартовом экране, число сообщений у персонажей и др.
- **Надписи** — «Ваше сообщение…», «1 пересланное сообщение», «печатает».
- **CSS** — свой CSS поверх темы.

«Сбросить всё» возвращает исходную тему.

## Экран загрузки без моргания (необязательно)
Первые секунды загрузки таверна показывает до темы, поэтому логотип ST мелькает красным. Чтобы он сразу был синим, скопируй `extras/user.css` в папку таверны `data/_css/user.css` (файл общий для всех профилей этой таверны).

## Для правок
- `src/theme.css` — стили, цвета — переменные `--vk-*`;
- `build.py` — палитры, иконки и сборка `theme/vk2017.json` (`python3 build.py`);
- `index.js` — кнопки, «печатает», шапка диалога, обновление темы; `editor.js` — редактор.
